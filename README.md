## Publicare pe GitHub Pages (2 minute, fără API)
1. Fă un repo nou pe github.com (ex: `hoinarii-site`)
2. În folderul `asociatia-hoinarii` rulează:
```
git init
git add .
git commit -m "site Hoinarii"
git branch -M main
git remote add origin https://github.com/NUMELE_TAU/hoinarii-site.git
git push -u origin main
```
3. În GitHub: Settings → Pages → Source: main / root → Save. Gata, link-ul apare în 1 minut.
